# java-exercises
### ⏰ HoraDoSistema

Exercício desenvolvido em **Java** como parte dos meus estudos em **Engenharia de Software**.

O programa tem como objetivo exibir a **hora atual do sistema**, servindo como um dos primeiros exercícios práticos para fixar conceitos básicos de Java e a organização de um projeto com Maven.

## 🎯 Objetivo

Praticar:

* Fundamentos da linguagem Java
* Estrutura de um projeto Maven
* Organização de código
* Execução de uma aplicação Java
* Uso do Git e GitHub para versionamento

## 🛠️ Tecnologias utilizadas

* **Java**
* **Maven**
* **Git**
* **GitHub**
* **NetBeans**

## 📂 Estrutura do projeto

```text
HoraDoSistema/
├── src/
│   └── main/
│       └── java/
│           └── primeiroprograma/
│               └── horadosistema/
│                   └── HoraDoSistema.java
├── pom.xml
└── README.md
```

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Abra o projeto no **NetBeans** ou em outra IDE compatível com Maven.

3. Execute a classe:

```text
HoraDoSistema.java
```

O programa exibirá no terminal a hora atual do sistema.

## 📚 Sobre este exercício

Este projeto faz parte da minha prática contínua em **Java**, com o objetivo de construir uma base sólida em programação e evoluir gradualmente para projetos mais completos.
